# LinkHub - 社交链接聚合平台

一个功能完整的 Linktree 风格的社交链接聚合 SaaS 平台。

## 功能特点

- 👤 用户注册和登录
- 📝 个人页面创建和管理
- 🔗 链接添加和管理
- 📊 访问和点击统计
- 🎨 美观的界面设计（企业简洁风）
- 🏃‍♂️ 简单的安装向导

## 目录结构

```
linkhub/
├── app/
│   ├── Controllers/        # 控制器
│   ├── Models/            # 数据模型
│   ├── Views/             # 视图文件
│   ├── Libraries/         # 核心类库
│   ├── Helpers/           # 辅助函数
├── config/               # 配置文件
├── database/             # 数据库迁移
├── public/               # Web 根目录
│   ├── assets/           # 静态资源
│   ├── install.php       # 安装程序
│   └── index.php         # 入口文件
├── routes/               # 路由文件
├── templates/            # 页面主题
├── composer.json         # Composer 配置
└── README.md             # 项目文档
```

## 技术栈

- 后端：PHP 7.4+（原生，无重型框架）
- 数据库：MySQL 5.7+ / MariaDB
- 前端：HTML5, CSS3, Tailwind CSS
- 部署：支持宝塔面板和虚拟主机

## 安装步骤

### 1. 上传文件

将项目文件上传到你的网站根目录。

### 2. 访问安装向导

在浏览器中访问：`http://your-domain.com/install.php`

### 3. 环境检测

安装向导会自动检查服务器环境是否满足要求：
- PHP 版本 ≥ 7.4
- PDO 扩展
- GD 扩展
- mbstring 扩展
- 目录写入权限

### 4. 配置信息

填写以下信息：
- 站点名称
- 站点 URL
- 管理员邮箱和密码
- 数据库连接信息

### 5. 完成安装

安装完成后，**务必删除 install.php 文件**，然后使用管理员账号登录管理后台。

## 快速开始

1. 注册账号
2. 创建你的第一个链接页面
3. 添加社交媒体链接
4. 分享你的页面链接！

## 路由说明

- `/` - 首页
- `/login` - 登录页面
- `/register` - 注册页面
- `/dashboard` - 用户后台
- `/pages/create` - 创建新页面
- `/pages/{id}/edit` - 编辑页面
- `/{slug}` - 公开页面访问
- `/{slug}/qr` - 生成二维码
